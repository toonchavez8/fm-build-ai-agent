# Build an AI Agent from Scratch v2 — Live Class Notes

## Prerequisites

- Node.js ≥ 22 (`node -v` to verify)
- OpenAI API key stored as `OPENAI_API_KEY` in your preferred `.env` file

## Setup

1. Duplicate `.env.example` → `.env` (or create `.env` if none exists).
2. Add `OPENAI_API_KEY="sk-..."`.
3. Install dependencies: `npm install`.
4. Run sanity checks: `npm run lint && npm test`.
